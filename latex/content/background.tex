\subsection{GGM trees}
\paragraph{Pseudorandom functions.}
A central problem in cryptography is generating randomness that appears truly 
random while remaining reproducible from a secret key. A 
\textbf{pseudorandom function} (PRF) addresses this problem: it is a keyed function 
that, to any efficient adversary without the key, is indistinguishable from a truly 
random function. Intuitively, a PRF expands a short secret key into an exponentially 
large table of ``random-looking'' outputs without storing the table explicitly.

PRFs are fundamental primitives in symmetric cryptography and appear in the 
construction of message authentication codes (MACs), stream ciphers, and 
key-derivation functions. 
%For example, \textsc{AES} in counter mode defines a 
%PRF: given a secret key~$k$ and an index~$i$, the output $\mathrm{AES}_k(i)$ is 
%computationally indistinguishable from a uniformly random string.
A standard construction of PRFs from one-way functions is the 
\textbf{Goldreich--Goldwasser--Micali (GGM) tree}~\cite{GGM86}, which builds a 
PRF by iteratively applying a pseudorandom generator along the branches of a 
binary tree indexed by the input bits. GGM trees are the main PRF construction 
studied in this work.


\begin{definition}[GGM Tree]
\label{def:ggm}
Let $\PRG : \{0,1\}^{\lam} \to \{0,1\}^{2\lam}$ be a length-doubling pseudorandom
generator, decomposed as $\PRG(x) = (\PRGl(x),\, \PRGr(x))$, where $\PRGl$ and
$\PRGr$ each output $\lam$ bits.  Given a root seed
$\seed_r \in \{0,1\}^{\lam}$ and a depth $d$, the \emph{GGM tree} is a complete
binary tree of depth $d$ in which:
\begin{itemize}
  \item the root holds $\seed_r$;
  \item each internal node $v$ storing seed $s$ generates its left child as
        $\PRGl(s)$ and its right child as $\PRGr(s)$;
  \item the $2^{d}$ leaves are the \PRG\ outputs at depth $d$.
\end{itemize}
\end{definition}

The crucial property exploited by ZK signature schemes is the
\emph{punctured-PRF property}: given all leaf seeds \emph{except} leaf~$i$, it is
computationally infeasible to recover the seed at leaf~$i$, provided $\PRG$ is
a secure pseudorandom generator.  This makes the \GGM\ tree suitable for hiding
one or more seeds while revealing the rest, as shown in Figure~\ref{fig:ggm-receiver}.

\paragraph{Incomplete \GGM\ trees.}
When the number of required leaves $t$ is not a power of $2$, a scheme may use an
\emph{incomplete} tree: leaves appear at multiple levels, and internal nodes near
the bottom may have fewer than two children or act as leaves themselves.  This
reduces memory and computation, but the additional index-tracking logic introduces
new fault surfaces.

\subsection{Attack targets}

This section provides an overview of the signature schemes, to which we apply our generalized
model and against which we carry out our attacks. 

\textbf{LESS-v2.}
\label{sec:less}
LESS (Linear Equivalence Signature Scheme)~\cite{LESS-spec} uses a Fiat--Shamir
transformation over a 3-pass Sigma protocol whose security rests on the Canonical
Form Linear Equivalence Problem (CF-LEP).  During signing, the signer must
generate $t$ independent ephemeral monomial matrices
$\mathbf{Q}_{e_0}, \ldots, \mathbf{Q}_{e_{t-1}} \in \Mon_n(q)$.
\paragraph{Role of the GGM tree in signing and verification.}
Each leaf $\eseed_i$, for $0 \le i < t$, is an ephemeral seed of length $\lambda$
bits from which the $i$-th monomial map $\mathbf{Q}_{e_i} \in \Mon_n(q)$ is
derived by expanding $\eseed_i$ through a PRNG\@.
The tree thus compactly encodes all $t$ independent ephemeral matrices required
by the iterated Sigma protocol from a single master seed $\mathsf{mseed} \in
\{0,1\}^\lambda$.

During signing, the Fiat--Shamir challenge vector
$\mathbf{b} = (b[0],\ldots,b[t-1]) \in \mathcal{S}_{t,w}$ partitions the
rounds into two sets: the $w$ rounds with $b[i]\neq 0$, for which the signer
publishes $\CosetRep(\pi_{b[i]}\circ\tilde{\pi}^*_i)$ and must \emph{conceal}
$\eseed_i$, and the remaining $t-w$ rounds, for which $\eseed_i$ itself is
disclosed so that the verifier can re-derive $\mathbf{Q}_{e_i}$ and
re-compute the commitment $\mathrm{CF}(A_i)$.

On the verifier side, each received node is expanded downward by the PRNG
until all required leaves are reconstructed; the hidden leaves, corresponding
to rounds with $b[i]\neq 0$, are never reachable from any published node,
so the ephemeral seeds $\eseed_i$ remain protected.

\paragraph{Secret-extraction opportunity.}
For every round $i$ with $b[i] \neq 0$, the signer publishes
$\CosetRep\!\bigl(\pi_{b[i]} \circ \tilde{\pi}^{*}_i\bigr)$
while keeping $\eseed_i$ hidden.  If an attacker obtains both values
simultaneously, Theorem~2 of~\cite{FaultToForge2025} shows that the secret
permutation $\pi_{b[i]}$ is recoverable.  The flag tree is the
\emph{sole enforcement mechanism} that prevents this dual revelation.

\textbf{CROSS.}
\label{sec:cross}
CROSS (Codes and Restricted Objects Signature Scheme)~\cite{CROSSspec} is based on
the Restricted Syndrome Decoding Problem (R-SDP)~\cite{BaldiBPSWW24} and applies the
Fiat--Shamir transform to a 5-pass ($q_2$-identification) protocol.
Like MEDS, CROSS uses a \emph{binary} fixed-weight challenge vector
$\mathbf{c} = (c_0, \ldots, c_{t-1}) \in \{0,1\}^t$ of weight $w$,
so the hidden and revealed index sets are
$\calH = \{i : c_i = 1\}$ and $\calR = \{i : c_i = 0\}$,
identical in structure to MEDS.

\paragraph{Role of the seed tree in signing and verification.}
Each leaf $\mathsf{Seed}_i$, for $0 \le i < t$, is a $\lambda$-bit
ephemeral seed from which the pair of randomness vectors
$({\bf e}'_i,\, {\bf u}'_i) \in G \times \mathbb{F}_p^n$ is derived via
$\mathsf{CSPRNG}(\mathsf{Seed}_i)$.
These vectors are the sole secret material for round $i$: from them the
signer computes the linear transitive map ${\bf v}_i = {\bf e} \star
({\bf e}'_i)^{-1} \in G$ and the two commitments
$\mathsf{cmt}_0[i] = \mathrm{Hash}(({\bf v}_i \star {\bf u}'_i){\bf H}^\top
\mid {\bf v}_i)$ and $\mathsf{cmt}_1[i] = \mathrm{Hash}({\bf u}'_i \mid
{\bf e}'_i)$.
The seed tree thus compactly encodes all $t$ pairs of ephemeral vectors
required by the iterated Sigma protocol from a single master seed.

During signing, the Fiat--Shamir second challenge vector
$\mathsf{chall}_2 \in \mathcal{B}(t,w)$ of fixed Hamming weight $w$ partitions
the rounds into two sets: the $w$ rounds with $\mathsf{chall}_2[i] = 1$,
for which the signer publishes the explicit response
$\mathsf{resp}[i] = ({\bf y}_i, {\bf v}_i)$ and must \emph{conceal}
$\mathsf{Seed}_i$, and the remaining $t - w$ rounds with
$\mathsf{chall}_2[i] = 0$, for which $\mathsf{Seed}_i$ itself is disclosed
so that the verifier can re-expand $({\bf e}'_i, {\bf u}'_i)$, recompute
${\bf y}_i = {\bf u}'_i + \mathsf{chall}_1[i] \cdot {\bf e}'_i$, and
recover $\mathsf{cmt}_1[i]$.

Additionally, CROSS uses a parallel \emph{Merkle tree} over the $t$
commitments $\mathsf{cmt}_0[i]$ to avoid transmitting all $t$ digests
explicitly: for the $w$ rounds where $\mathsf{chall}_2[i] = 1$, the
corresponding $\mathsf{cmt}_0[i]$ values cannot be recomputed by the
verifier (since $\mathsf{Seed}_i$ is hidden), and are instead authenticated
via a Merkle proof of size $O(w \log t)$.

On the verifier side, the received seed-path nodes are expanded downward to
reconstruct all unrevealed leaf seeds; the $w$ hidden seeds, corresponding
to rounds with $\mathsf{chall}_2[i] = 1$, are provably unreachable from any
published node, ensuring that the ephemeral vectors $({\bf e}'_i,
{\bf u}'_i)$ — and hence the secret key ${\bf e}$ — remain protected.

\paragraph{Secret-extraction opportunity.}
For round $i$ with $c_i = 1$, the signer reveals a ZK response encoding the
relationship between $\eseed_i$ and the long-term secret R-SDP solution.
If an attacker obtains both the response and $\eseed_i$, the secret is
recoverable by the linear-algebra argument of ZKFault~\cite{ZKFault},
which demonstrated full key recovery from a single fault for CROSS.

\textbf{MEDS.}
\label{sec:meds}
MEDS (Matrix Equivalence Digital Signature)~\cite{ChouNPRRST23} is a code-based
signature scheme whose security rests on the Matrix Code Equivalence Problem
(MCEP).  Like LESS, it applies the Fiat--Shamir transform to a 3-pass Sigma
protocol between a prover holding a secret equivalence
$(A, B) \in \GL_k(q) \times \GL_n(q)$ and a verifier.

\paragraph{Role of the seed tree in signing and verification.}
Each leaf $\sigma_i$, for $0 \le i < t$, is an ephemeral seed of length
$\ell_{\mathrm{tree\_seed}}$ bytes from which the $i$-th pair of ephemeral
invertible matrices $(\tilde{A}_i, \tilde{B}_i) \in \GL_m(q) \times \GL_n(q)$
is sampled via a PRNG\@.
The commitment for round $i$ is then $h_i = H\!\bigl(\mathrm{SF}(\pi_{\tilde{A}_i,
\tilde{B}_i}(G_0))\bigr)$, so the seed tree compactly encodes all $t$ ephemeral
matrix pairs required by the iterated Sigma protocol from a single master seed
$\rho_{0,0} \in \mathcal{B}^{\ell_{\mathrm{tree\_seed}}}$.

During signing, the Fiat--Shamir challenge string
$\mathbf{h} = (h_0, \ldots, h_{t-1}) \in \{0, \ldots, s-1\}^t$ of fixed
weight~$w$ partitions the rounds into two sets: the $w$ rounds with
$h_i \neq 0$, for which the signer publishes the coset representative
$(\mu_i, \nu_i) = (A\tilde{A}_i^{-1},\, B^{-1}\tilde{B}_i)$ and must
\emph{conceal} $\sigma_i$, and the remaining $t - w$ rounds with $h_i = 0$,
for which $\sigma_i$ is disclosed so that the verifier can re-expand
$(\tilde{A}_i, \tilde{B}_i)$ and recover the commitment $h_i$.

On the verifier side, the required leaf seeds are recovered; the $w$ hidden seeds, corresponding to
rounds with $h_i \neq 0$, are provably unreachable from any published node.

\paragraph{Key Generation.}
Algorithm~\ref{alg:keygen_meds} is the simplification of the key generation.
It begins by sampling a master secret seed $\delta$ and immediately
deriving two sub-seeds via $\XOF$: a \emph{public} seed $\sigma_{G_0}$, used to
expand the base systematic matrix $G_0 \in \mathbb{F}_q^{k \times mn}$, and a
\emph{private} chaining seed $\sigma$ that is used in the rest of the process.
For each of the $s-1$ public keys, the algorithm performs a
\emph{compressed key-generation} step: a secret invertible matrix $T_i \in
\GL_k(q)$ twists $G_0$ into $G'_0 = T_i G_0$, and a structured linear system
(the $\mathrm{Solve}$ step, made efficient by fixing $P_0 = I_m$ and
$P_1 = U_m$) recovers the equivalence pair $(A_i, B_i) \in \GL_m(q) \times
\GL_n(q)$ satisfying $G_i = \SF(\pimap{A_i}{B_i}(G_0))$.
The public key stores only the seed $\sigma_{G_0}$ and the compressed matrices
$G_1, \ldots, G_{s-1}$; the secret key retains $\delta$ together with the
stored inverses $A_i^{-1}$, $B_i^{-1}$---the sole secret material consumed
at signing time.

\begin{algorithm}[t]
\scriptsize
\caption{MEDS Key Generation (simplified)}
\label{alg:keygen_meds}
\KwIn{---}
\KwOut{Public key $\pk$, secret key $\sk$}

$\delta \xleftarrow{\$} \mathcal{B}^{\ell_{\mathrm{sec\_seed}}}$\;
$\sigma_{G_0},\, \sigma \leftarrow \XOF(\delta,\, \ell_{\mathrm{pub\_seed}},\, \ell_{\mathrm{sec\_seed}})$\;
$G_0 \leftarrow \ExpandSystMat(\sigma_{G_0})$\;

\For{$i = 1$ \KwTo $s-1$}{
    $\sigma_a,\, \sigma_{T_i},\, \sigma \leftarrow \XOF(\sigma,\, \ell_{\mathrm{sec\_seed}},\, \ell_{\mathrm{sec\_seed}},\, \ell_{\mathrm{sec\_seed}})$\;
    $T_i \leftarrow \ExpandInvMat(\sigma_{T_i},\, k)$\;
    $a_{m-1,m-1} \leftarrow \ExpandFqs(\sigma_a,\, 1)$\;
    $G'_0 \leftarrow T_i G_0$\;
    $(A_i,\, B_i^{-1}) \leftarrow \Solve(G'_0,\, a_{m-1,m-1})$
    \quad \tcp{Fail $\Rightarrow$ retry from line 5}
    $G_i \leftarrow \SF\!\bigl(\pimap{A_i}{B_i}(G_0)\bigr)$
    \quad \tcp{$\perp\Rightarrow$ retry from line 5}
}

$\pk \leftarrow \bigl(\sigma_{G_0} \big| \CompressG(G_1) \big| \cdots \big| \CompressG(G_{s-1})\bigr)$\;
$\sk \leftarrow \bigl(\delta \big| \sigma_{G_0} \big| \Compress(A_1^{-1}) \big| \cdots \big| \Compress(A_{s-1}^{-1}) \big| \Compress(B_1^{-1}) \big| \cdots \big| \Compress(B_{s-1}^{-1})\bigr)$\;
\Return $\pk,\, \sk$
\end{algorithm}


\paragraph{Signing.}
Algorithm~\ref{alg:sign_meds} is the simplification of the signing algorithm.
A fresh master seed $\delta$ is drawn and expanded into a tree-root seed $\rho$
and a salt $\alpha$; the seed tree $\SeedTree_t(\rho, \alpha)$ then materialises
all $t$ leaf seeds $\sigma_0, \ldots, \sigma_{t-1}$ at once.
For every round $i$, a pair of ephemeral matrices
$(\tilde{A}_i, \tilde{B}_i) \in \GL_m(q) \times \GL_n(q)$ is expanded from
$\sigma_i$ (together with $\alpha$ and an address for domain separation), and
the commitment $\tilde{G}_i = \SF(\pimap{\tilde{A}_i}{\tilde{B}_i}(G_0))$ is
computed.  Hashing all non-systematic parts of the $\tilde{G}_i$ alongside the
message yields the digest $d$, which is parsed into the fixed-weight challenge
vector $(h_0, \ldots, h_{t-1})$.  For each \emph{non-zero} challenge $h_i$,
the signer releases the coset representative
$(\mu_i, \nu_i) = (\tilde{A}_i A_{h_i}^{-1},\, B_{h_i}^{-1} \tilde{B}_i)$;
the remaining seeds are transmitted compactly via a seed-tree path $p$.

\begin{algorithm}[t]
\scriptsize
\caption{MEDS Signing (simplified)}
\label{alg:sign_meds}
\KwIn{Secret key $\sk$, message $m$}
\KwOut{Signed message $m_s$}

Parse $\sk$ to recover $\sigma_{G_0}$, and $A_i^{-1}$, $B_i^{-1}$ for $i=1,\ldots,s-1$\;
$G_0 \leftarrow \ExpandSystMat(\sigma_{G_0})$\;

$\delta \xleftarrow{\$} \mathcal{B}^{\ell_{\mathrm{sec\_seed}}}$\;
$\rho,\, \alpha \leftarrow \XOF(\delta,\, \ell_{\mathrm{tree\_seed}},\, \ell_{\mathrm{salt}})$\;
$(\sigma_0, \ldots, \sigma_{t-1}) \leftarrow \SeedTree_t(\rho,\, \alpha)$\;

\For{$i = 0$ \KwTo $t-1$}{
    $\sigma'_i \leftarrow \bigl(\alpha \big| \sigma_i \big| \ToBytes(2^{1+\lceil\log_2 t\rceil}+i,\,4)\bigr)$\;
    $\sigma_{\tilde{A}_i},\, \sigma_{\tilde{B}_i} \leftarrow \XOF(\sigma'_i,\, \ell_{\mathrm{pub\_seed}},\, \ell_{\mathrm{pub\_seed}})$\;
    $\tilde{A}_i \leftarrow \ExpandInvMat(\sigma_{\tilde{A}_i},\, m)$;\quad
    $\tilde{B}_i \leftarrow \ExpandInvMat(\sigma_{\tilde{B}_i},\, n)$\;
    $\tilde{G}_i \leftarrow \SF\!\bigl(\pimap{\tilde{A}_i}{\tilde{B}_i}(G_0)\bigr)$
    \quad\tcp{$\perp\Rightarrow$ resample $\sigma'_i$}
}

$d \leftarrow H\!\bigl(\Compress(\tilde{G}_0[\,;k,mn{-}1])\big|\cdots\big|\Compress(\tilde{G}_{t-1}[\,;k,mn{-}1])\big|m\bigr)$\;
$(h_0,\ldots,h_{t-1}) \leftarrow \ParseHash_{s,t,w}(d)$\;

\For{$i = 0$ \KwTo $t-1$ \textbf{with} $h_i > 0$}{
    $\mu_i \leftarrow \tilde{A}_i \cdot A_{h_i}^{-1}$;\quad
    $\nu_i \leftarrow B_{h_i}^{-1} \cdot \tilde{B}_i$\;
    Append $\bigl(\Compress(\mu_i)\big|\Compress(\nu_i)\bigr)$ to response vector $v$\;
}

$p \leftarrow \SeedTreeToPath_t(h_0,\ldots,h_{t-1},\,\rho,\,\alpha)$\;
\Return $m_s \leftarrow \bigl(v \big| p \big| d \big| \alpha \big| m\bigr)$
\end{algorithm}


\paragraph{Verification.}
Algorithm~\ref{alg:verify_meds} is the simplification of the verification algorithm.
The verifier first reconstructs the public matrices $G_0, G_1, \ldots, G_{s-1}$
from the public key and parses the signed message to recover the path $p$, the
digest $d$, the salt $\alpha$, and the $w$ response pairs.
The challenge vector $(h_0, \ldots, h_{t-1})$ is recomputed from $d$, and
$\PathToSeedTree_t$ recovers the $t-w$ disclosed leaf seeds from $p$.
For each round $i$, one of two paths is taken: if $h_i > 0$, the verifier
applies the published coset representative $(\mu_i, \nu_i)$ to the
corresponding public matrix $G_{h_i}$ and checks invertibility before
computing $\hat{G}_i = \SF(\pimap{\mu_i}{\nu_i}(G_{h_i}))$; if $h_i = 0$,
the verifier re-expands $(\hat{A}_i, \hat{B}_i)$ from the recovered seed and
computes $\hat{G}_i = \SF(\pimap{\hat{A}_i}{\hat{B}_i}(G_0))$.
Finally, the recomputed digest $d'$ is compared to $d$; equality confirms the
signature.

\begin{algorithm}[t]
\scriptsize
\caption{MEDS Verification (simplified)}
\label{alg:verify_meds}
\KwIn{Public key $\pk$, signed message $m_s$}
\KwOut{Message $m$ or $\perp$}

$G_0 \leftarrow \ExpandSystMat(\pk[0,\ell_{\mathrm{pub\_seed}}{-}1])$\;
\For{$i = 1$ \KwTo $s-1$}{
    $G_i \leftarrow \DecompressG(\pk[\cdots])$\;
}

Parse $m_s$ to obtain: response pairs $((\mu_i,\nu_i))_{h_i>0}$, path $p$, digest $d$, salt $\alpha$, message $m$\;
$(h_0,\ldots,h_{t-1}) \leftarrow \ParseHash_{s,t,w}(d)$\;
$(\sigma_0,\ldots,\sigma_{t-1}) \leftarrow \PathToSeedTree_t(h_0,\ldots,h_{t-1},\,p,\,\alpha)$\;

\For{$i = 0$ \KwTo $t-1$}{
    \eIf{$h_i > 0$}{
        $(\mu_i,\,\nu_i) \leftarrow$ next response pair from $m_s$\;
        \lIf{$\mu_i \notin \GL_m(q)$ \textbf{or} $\nu_i \notin \GL_n(q)$}{\Return $\perp$}
        $\hat{G}_i \leftarrow \SF\!\bigl(\pimap{\mu_i}{\nu_i}(G_{h_i})\bigr)$\;
        \lIf{$\hat{G}_i = \perp$}{\Return $\perp$}
    }{
        $\sigma'_i \leftarrow \bigl(\alpha \big| \sigma_i \big| \ToBytes(2^{1+\lceil\log_2 t\rceil}+i,\,4)\bigr)$\;
        $\hat{A}_i \leftarrow \ExpandInvMat(\XOF(\sigma'_i)_1,\, m)$;\quad
        $\hat{B}_i \leftarrow \ExpandInvMat(\XOF(\sigma'_i)_2,\, n)$\;
        $\hat{G}_i \leftarrow \SF\!\bigl(\pimap{\hat{A}_i}{\hat{B}_i}(G_0)\bigr)$\;
    }
}

$d' \leftarrow H\!\bigl(\Compress(\hat{G}_0[\,;k,mn{-}1])\big|\cdots\big|\Compress(\hat{G}_{t-1}[\,;k,mn{-}1])\big|m\bigr)$\;
\lIf{$d = d'$}{\Return $m$}
\Return $\perp$
\end{algorithm}


\paragraph{Secret-extraction opportunity.}
For round $i$ with $h_i = 1$, the signer reveals its ZK response.  If an attacker
obtains both the response and $\eseed_i$, the secret equivalence pair $(A, B)$ is
recoverable by linear algebra.  The Reference Tree is the sole enforcement mechanism
preventing this dual revelation.

\subsubsection{MPCitH / VOLEitH Family (FAEST, Mirath, SDitH, RYDE)}
\label{sec:mpcith}
% ============================================================

\paragraph{Context.}
MPC-in-the-Head (MPCitH) schemes use the \GGM tree in a more
elaborate but structurally analogous way.  They generate $N$ virtual
\emph{party shares} for each of $\tau$ parallel repetitions.  For repetition $e$,
the Fiat--Shamir challenge selects one hidden party index
$i^*_e \in \{0, \ldots, N-1\}$.  The \GGM\ tree lets the signer reveal all $N-1$
non-hidden shares using $O(\log N)$ published intermediate seeds.

\paragraph{Tree types.}
\begin{itemize}
  \item \textbf{Classic MPCitH (Mirath, RYDE).}
        A forest of $\tau$ independent complete binary trees, each with $N$
        leaves.  All roots are derived from a single master seed via $\XOF$.
  \item \textbf{VOLEitH (FAEST, SDitH v2).}
        A single large \GGM\ tree with $\tau \times N$ leaves, as described
        in~\cite{OneTree}.  Child-node generation uses $\PRG = \text{AES-CTR}$
        (FAEST) or SHAKE (SDitH).
\end{itemize}

The all-but-one vector commitment (AVC / BAVC) mechanism is the MPCitH counterpart
of the flag tree.  For each repetition $e$, the signer publishes the
\emph{co-path}: the sequence of sibling nodes along the path from the hidden leaf
$i^*_e$ to the root.  The verifier can re-expand all $N-1$ non-hidden leaf seeds
from the co-path alone.  This is structurally the \GGM-path mechanism with
exactly one hidden leaf per repetition, and the same fault surfaces (index
arithmetic, loop increments, conditional branch) apply.

In LESS, MEDS, and CROSS, the secret is a permutation or matrix equivalence
embedded in the hidden seed's ephemeral commitment.  In MPCitH, the hidden seed
generates the prover's witness share.  In both cases the invariant is identical:
the signer must never simultaneously reveal both the hidden leaf seed \emph{and}
the corresponding ZK response for the same round.
